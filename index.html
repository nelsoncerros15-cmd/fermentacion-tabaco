📖 Lógica del sistema

🌿 MOJA (1era / 2da / 3era)
• REALIZADO = NO → Días acumulan automáticamente: HOY − Mes Prog.
• REALIZADO = Fecha → Conteo fijo: Fecha − Mes Prog.

📦 SOLTAR
• SUELTO = NO → Pendiente soltar, días acumulan
• SUELTO = Fecha + ACOND = NO → ⚠️ Suelto, pend. acondicionar
• SUELTO = Fecha + ACOND = Fecha → ✅ Completo, días = Acond. − Mes Prog.
